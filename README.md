# Gestion de classe

## Description
Application développée en Python pour faciliter la gestion des élèves et de leurs notes.

## Fonctionnalités
- Ajouter un élève
- Afficher la liste des élèves
- Rechercher un élève
- Modifier le nom d'un élève
- Modifier une note
- Supprimer un élève
- Calculer la moyenne de la classe
- Identifier le meilleur élève
- Calculer le taux de réussite
- Afficher les résultats scolaires

## Technologies utilisées
- Python
